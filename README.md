# hxyfront-62007 植物标本馆复份交换装箱台

源提示词编号：9

植物标本馆压制标本入库与复份交换前端。工作人员登记采集号、物种名称、采集地点、海拔、
生境、采集人、压制状态、鉴定状态与柜位；复份交换按外馆分箱装箱，替代纸单排箱。

## 装箱业务口径

- **入箱条件**：鉴定接受、已上柜、不在已封存（在途交换）箱中、未放进别的箱。
- **按外馆分箱**：每个交换箱归属一个外馆（PE / KUN / IBSC），可随时新建箱。
- **同一采集号只留一份**：候选列表按采集号去重；该馆已留档的采集号不能再装。
- **箱满封存**：每箱 12 份，满了才能封存进入在途交换，封存后不可改动。
- **收到退回**：在途箱逐份勾选退回 / 接受——
  - 退回份：回到「待复核」（鉴定状态重置、释放柜位、离开交换箱）；
  - 接受份：外馆继续留档，不再占箱内槽位；
  - 箱子转为装箱中，空槽可补别的标本，留档记录保留在箱上。
- **浏览器持久化**：入库队列、柜位、详情页、装箱台读写同一份 localStorage 数据，
  重开浏览器可继续处理；页头可重置为演示种子数据。

## 三个业务文件

| 文件 | 职责 |
| --- | --- |
| `src/business/store.ts` | 资料存取：类型、种子数据、localStorage 读写、柜位表 |
| `src/business/packing.ts` | 装箱判定：入箱资格、同号唯一、箱满封存、退回处理、队列筛选（纯函数） |
| `src/business/state.tsx` | 界面状态：reducer + `useAppData`，所有界面修改的唯一入口，自动持久化 |

页面组件位于 `src/components/`：入库队列 `IntakeQueue`、装箱台 `PackingStation`、
柜位 `CabinetMap`、标本详情 `SpecimenDetail`。

## 技术栈

React 19 + Vite 7 + TypeScript（localStorage，无后端）
