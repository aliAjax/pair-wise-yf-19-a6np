# hxyfront-62007 植物标本馆入库

源提示词编号：9

开发一个植物标本馆压制标本入库前端项目，工作人员可以录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面需要有入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 复份交换装箱台

在入库功能基础上补建装箱台，取代纸单排箱：

- **入箱硬规则**（`src/business/packing.ts` 纯函数判定）：仅「鉴定接受 + 已上柜有柜位 + 未在其他交换箱（不在途/未封存）」的标本可入箱；未上柜或已放进别的箱会被拦截并给出原因。
- **箱子按外馆分开**，为每个收箱外馆独立建箱；**同一采集号（复份）在同一外馆的箱中只留一份**，复份须分送不同外馆。
- **箱满封存**：装满后自动封存（未满时封存按钮禁用），封存后寄出进入「在途交换」。
- **收到退回**：被外馆接受的标本继续留档；被退回的那份回到「待复核」并暂离柜位；箱子清空回到装箱中，**空位可补别的标本**，往轮结果保留在箱周期记录中。
- 入库队列、馆藏柜位、详情页与装箱台读**同一份浏览器数据**（localStorage，键 `hxyfront-62007-herbarium-v1`），重开浏览器仍可继续处理。

### 业务文件划分（src/business/）

| 文件 | 职责 |
| --- | --- |
| `storage.ts` | 资料存取：数据结构、种子数据、localStorage 读写 |
| `packing.ts` | 装箱判定：入箱/封存/空位/候选分组等纯规则 |
| `store.ts` | 界面状态：页签、筛选、选中箱、操作动作与提示 |
